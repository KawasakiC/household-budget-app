# 4. SCR-001 家計簿トップ

## 4.1 画面概要

当月の家計状況を確認するためのトップ画面。

予算・支出・カテゴリごとの残金など、現在の家計状況をまとめて確認できるようにする。

## 4.2 画面イメージ

```text
┌─────────────────────────────────────────────┐
│ 家計簿Webアプリ                              │
├─────────────────────────────────────────────┤
│                                              │
│ 2026年10月                                   │
│                                              │
│ ┌───────┐  ┌───────┐       │
│ │ 今月の残金   │  │ 残り日数     │       │
│ │ ¥120,000     │  │ 20日         │       │
│ └───────┘  └───────┘       │
│                                              │
│ 支出合計                                     │
│ ¥80,000                                      │
│                                              │
│             [ ＋ 支出を登録 ]                │
│                                              │
│ ── カテゴリ別残金 ──                     │
│                                              │
│ 食費       ¥30,000                           │
│ 日用品     ¥10,000                           │
│ 車         ¥10,000                           │
│ 医療費     ¥10,000                           │
│ 娯楽費     ¥30,000                           │
│                                              │
│ 食費の週予算                                 │
│ ¥7,500 / 週                                  │
│                                              │
│ ── 最近の支出 ──                         │
│                                              │
│ 10/01  食費       ¥1,200  ○○スーパー       │
│ 09/30  日用品     ¥2,500  △△ドラッグ       │
│ 09/29  食費       ¥3,000  ○○スーパー       │
│ 09/28  医療費     ¥1,000  ○○駅             │
│ 09/27  娯楽費     ¥4,000  ○○店             │
│                                              │
└─────────────────────────────────────────────┘
```

## 4.3 表示項目

| 項目 | 内容 |
|---|---|
| 対象年月 | 当月を表示する |
| 今月の残金 | 月予算から当月の支出合計を差し引いた金額 |
| 月末までの残り日数 | 現在日から対象月の月末までの日数 |
| 支出合計 | 当月の支出合計 |
| 支出を登録 | 支出登録画面への遷移ボタン |
| カテゴリごとの残金 | カテゴリ予算からカテゴリ別支出実績を差し引いた金額 |
| 食費の週予算 | 食費の残金をもとに算出した週あたりの予算 |
| 最近の支出 | 支出日の新しい順に5件表示 |

## 4.4 操作

- 「支出を登録」から支出登録画面へ遷移できる
- 「予算設定」から予算設定画面へ遷移できる
- 「予算・実績」から予算・実績画面へ遷移できる
- 「支出一覧」から支出一覧画面へ遷移できる
- 最近の支出から対象の支出を選択して編集画面へ遷移できる

# 5. SCR-002 予算設定

## 5.1 画面概要

対象月の予算を自動計算し、内容を確認・修正して確定する画面。

## 5.2 画面イメージ

```text
┌─────────────────────────────────────────────┐
│ 予算設定                                     │
├─────────────────────────────────────────────┤
│                                              │
│ 対象月                                       │
│ [ 2026年10月 ▼ ]                            │
│                                              │
│              [ 自動計算 ]                    │
│                                              │
│ ──────────────────────────────────────────── │
│ カテゴリ        予算額                       │
│ ──────────────────────────────────────────── │
│ 食費            [ ¥30,000 ]                  │
│ 日用品          [ ¥10,000 ]                  │
│ 車              [ ¥10,000 ]                  │
│ 医療費          [ ¥10,000 ]                  │
│ 娯楽費          [ ¥30,000 ]                  │
│ ──────────────────────────────────────────── │
│ 合計            ¥90,000                      │
│                                              │
│              [ 予算を確定する ]              │
│                                              │
└─────────────────────────────────────────────┘
```

## 5.3 入力・表示項目

| 項目 | 種別 | 必須 | 内容 |
|---|---|---|---|
| 対象月 | 選択 | ○ | 予算を設定する年月 |
| カテゴリ | 表示 | - | 予算カテゴリ |
| 予算額 | 入力 | ○ | 自動計算された金額を変更可能 |
| 合計 | 表示 | - | カテゴリごとの予算合計 |

## 5.4 ボタン

### 自動計算

対象月の予算を計算し、各カテゴリの予算額を表示する。

### 予算を確定する

表示されている予算を対象月の予算として保存する。

# 6. SCR-003 予算・実績

## 6.1 画面概要

対象月の予算と実際の支出をカテゴリごとに比較する。

## 6.2 画面イメージ

```text
┌────────────────────────┐
│ 予算・実績                                     │
├────────────────────────┤
│                                                │
│ 対象月 [ 2026年10月 ▼ ]                       │
│                                                │
│ ─────────────────────── │
│ カテゴリ   予算      実績      残予算   消化率 │
│ ─────────────────────── │
│ 食費      ¥30,000   ¥25,000    ¥5,000    83%   │
│ 日用品    ¥10,000   ¥12,000   -¥2,000   120%   │
│ 車        ¥10,000    ¥3,000    ¥7,000    30%   │
│ 医療費    ¥10,000    ¥5,000    ¥5,000    50%   │
│ 娯楽費    ¥30,000   ¥10,000   ¥20,000    33%   │
│ ─────────────────────── │
│ 合計      ¥90,000   ¥55,000   ¥35,000    61%   │
│                                                │
└────────────────────────┘
```

## 6.3 表示項目

| 項目 | 内容 |
|---|---|
| 対象月 | 比較対象となる年月 |
| カテゴリ | 支出カテゴリ |
| 予算 | カテゴリに設定された予算 |
| 支出実績 | 対象月のカテゴリ別支出合計 |
| 残予算 | 予算から支出実績を差し引いた金額 |
| 予算消化率 | 支出実績 ÷ 予算 × 100 |
| 合計 | 全カテゴリの合計 |

予算を超過しているカテゴリは、超過していることが分かる表示とする。

# 8. SCR-005 支出登録

## 8.1 画面概要

新しい支出を登録する。

## 8.2 画面イメージ

```text
┌───────────────────────┐
│ 支出登録                                     │
├───────────────────────┤
│                                              │
│ 支出日                                       │
│ [ 2026/10/01 ]                               │
│                                              │
│ 金額                                         │
│ [ 1,200 ]                                    │
│                                              │
│ カテゴリ                                     │
│ [ 食費 ▼ ]                                  │
│                                              │
│ 支払方法                                     │
│ [ 現金 ▼ ]                                  │
│                                              │
│ 店舗                                         │
│ [ ○○スーパー ]                             │
│                                              │
│ メモ                                         │
│ [ お昼ごはん ]                               │
│                                              │
│       [ 登録する ]    [ キャンセル ]         │
│                                              │

```

## 8.3 入力項目

| 項目 | 種別 | 必須 |
|---|---|---|
| 支出日 | 日付入力 | ○ |
| 金額 | 数値入力 | ○ |
| カテゴリ | 選択 | ○ |
| 支払方法 | 選択 | ○ |
| 店舗 | テキスト入力 | × |
| メモ | テキスト入力 | × |

## 8.4 操作

### 登録する

入力内容をチェックし、問題がなければ支出を登録する。

登録後は支出一覧画面へ遷移する。

### キャンセル

支出を登録せず、支出一覧画面へ戻る。

# 10. 入力・エラー表示

入力内容に問題がある場合は、該当項目の近くにエラーメッセージを表示する。

## 10.1 支出登録・編集

以下の場合にエラーとする。

- 支出日が未入力
- 金額が未入力
- 金額に不正な値が入力されている
- カテゴリが未選択
- 支払方法が未選択

例：

```text
金額
[ -100 ]

※金額は0円より大きい値を入力してください。
```

# 11. 画面間の主な操作

| 操作 | 遷移先 |
|---|---|
| トップ → 予算設定 | SCR-002 |
| トップ → 予算・実績 | SCR-003 |
| トップ → 支出一覧 | SCR-004 |
| トップ → 支出登録 | SCR-005 |
| 支出一覧 → 支出登録 | SCR-005 |
| 支出一覧 → 支出編集 | SCR-006 |
| 支出登録 → 登録完了 | SCR-004 |
| 支出編集 → 更新完了 | SCR-004 |
| 予算設定 → 確定完了 | SCR-003 |

---

# 12. 画面設計上の方針

- 1画面あたりの情報量を抑え、必要な情報を確認しやすくする
- 家計簿トップでは当月の状況を一目で確認できるようにする
- 入力画面では入力項目と操作方法を分かりやすくする
- 予算超過など、注意が必要な状態を分かりやすく表示する
- PCブラウザでの利用を前提とする
