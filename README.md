# 家計簿Webアプリ

JavaとSpring Bootで作成した、月ごとの予算と支出を管理するWebアプリ。支出を登録・集計し、予算の残金や支出に対する満足度を確認できる。

## 主な機能

### 家計簿トップページ

- 今月の支出合計と残金を表示
- 今日を含めた月末までの残り日数を表示
- カテゴリ別の残金を表示
- 食費の残金と月末までの土曜日数から、食費の週予算を計算
- 今月全体の満足度とコメントを表示
- 満足度が低いカテゴリを表示

### 予算設定

- 対象月ごとにカテゴリ別の予算を設定
- カテゴリの計算方法に応じて予算を自動計算
- 入力した予算額の合計を画面に表示
- 予算の確定と、同じ月・カテゴリの予算の上書き

予算額は0円も設定可能。

### 支出登録・編集

- 支出日、金額、カテゴリ、支払い方法、店舗、メモ、満足度を登録
- 登録済みの支出を編集

### 支出一覧

- 月ごとの支出を一覧表示
- カテゴリ別の支出額と残金を表示
- 満足度3以上の支出から「使ってよかった」支出を表示
- 支出を編集・削除

## 工夫したところ

### 満足度の集計とコメント

支出ごとの満足度を集計し、5点満点を基準にパーセントで表示する。割合に応じたコメントを表示し、金額だけでなく支出に対する満足度も振り返れるようにした。

### 気になるカテゴリの抽出

カテゴリごとに満足度を集計し、60%未満のカテゴリのうち、最も満足度が低いカテゴリを表示する。最低値が同率のカテゴリが複数ある場合は、該当するカテゴリをすべて表示する。支出がないカテゴリは判定対象から除外する。

### 計算処理の単体テスト

トップページ、予算設定、支出一覧で使う計算処理をServiceにまとめ、JUnitで単体テストを実施した。通常の値に加え、支出がない場合、予算が未確定の場合、満足度が同率の場合なども確認した。

## 動作環境

- Java 21
- PostgreSQL
- Maven Wrapper

## セットアップ

1. PostgreSQLにアプリ用のデータベースを作成する。
2. `src/main/resources/application.properties` のデータベース接続先、ユーザー名、パスワードを環境に合わせて設定する。
3. `db/db-init.sql` のテーブル作成・初期データ登録SQLをデータベースに適用する。

## 起動方法

プロジェクトのルートフォルダで実行する。

Windows:

```bat
mvnw.cmd spring-boot:run
```

macOS / Linux:

```bash
./mvnw spring-boot:run
```

起動後、ブラウザで `http://localhost:8080` を開く。

## テストの実行

Windows:

```bat
mvnw.cmd test
```

macOS / Linux:

```bash
./mvnw test
```

JUnitのテストコードは `src/test/java` に配置。
